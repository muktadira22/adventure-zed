### [Zed](https://zed.dev)

#### Install manually in Zed

1. Copy the `themes/adventure-zed.json` file to `~/.config/zed/themes/adventure-zed.json`.
   ```bash
   mkdir -p ~/.config/zed/themes
   cp themes/adventure-zed.json ~/.config/zed/themes/
   ```
2. Open Zed settings (`Cmd+,` or `Ctrl+,`).
3. Select `Adventure Zed` as your theme.
4. Enjoy coding! ✨
